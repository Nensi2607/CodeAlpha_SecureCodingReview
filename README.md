# 🔐 Secure Coding Review

## 📌 Project Overview
This project was developed as part of the CodeAlpha Cybersecurity Internship.

The objective of this project is to perform a secure coding review on a vulnerable Python login application, identify security weaknesses, and implement remediation techniques using secure coding practices.

---

## 🚀 Features
- Vulnerable login system
- Security vulnerability analysis
- Secure remediation implementation
- SHA-256 password hashing
- Security review report
- Vulnerable vs secure comparison

## 🚨 Vulnerabilities Identified
- Hardcoded credentials
- Plaintext password storage
- Weak authentication design

---

## 🔒 Security Improvements
- Password hashing using SHA-256
- Improved authentication workflow
- Better secure coding practices
